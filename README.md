# Pokédex Explorer

A responsive vanilla JavaScript Pokédex powered by [PokéAPI](https://pokeapi.co/).

## Features

- Loads up to 151 Pokémon in batches of 20
- Fetch-then-render flow with in-memory caching
- Lazy-loaded species and evolution data
- Clickable Main, Stats and Evolution Chain tabs in the detail view
- Partial-name search from 3 characters
- Type-colored cards, loading feedback and keyboard-friendly dialog
- Responsive layout down to 320 px
- Separate files for database values, caching and global state

## Start locally

Open the folder with VS Code and start `index.html` using Live Server.
